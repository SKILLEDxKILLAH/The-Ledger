# Project Memory

This is the default continuity canon seeded into The Ledger. It is editable
inside the app (Settings > Project Memory) and is sent to Claude as a **cached**
context block so recurring canon carries accurately into new builds without
re-typing it every time.

## Purpose and Context

March builds detailed AI character cards, scenario content, and bot profiles for
roleplay platforms (primarily JanitorAI) within an established production
pipeline: original fiction, fandom adaptations (e.g., Crescent City / Sarah J.
Maas), and interconnected shared-universe projects. March arrives with a fully
realized creative vision and uses Claude as a drafting and formatting partner,
not a creative lead. The prose skill `romantic-enchantment-style` is invoked at
the start of most writing tasks and shapes narrative-heavy sections (backstory,
scenario messages, intimacy content).

## Key Principles

- Cross-character continuity is a firm requirement; recurring NPC canon carries
  accurately into new builds.
- `{user}` is always a blank slate: no background, appearance, role, or inner
  state assigned, described, voiced, or acted for. He/him pronouns.
- March's edited version is always canonical: Claude drafts, March edits and
  submits, Claude acknowledges changes in a hyphenated list and locks the
  revision. No preemptive changelogs.
- Token ceilings are hard constraints; March's external tokenizer is
  authoritative. Targets: ~1,800-2,150 tokens per card; 700 per scenario
  message; 850 for a final/climax scenario; ~2,000 expanded ceiling on request
  for high-stakes scenes.
- Fandom spoiler discipline: late-series reveals seeded as menace or buried in
  Secrets, not surfaced in main lore.
- Revisions: drop-in replacement blocks with placement notes, then merged into a
  full reprint.
- Parents stay in Relationships only, not promoted to NPC block entries, unless
  specified.
- NPC descriptions: 70-96 words with a required hook clause; NPC block is the
  first trim candidate over ceiling.
- Residence architecture kept ambiguous to preserve player choice (no doormen,
  no specific home types implied).

## Formatting (non-negotiable)

No em dashes; third-person narration; plaintext narration/action; asterisks for
internal thoughts; quotation marks for dialogue; contractions in dialogue and
internal monologue; `{user}` never voiced, described, or acted for; `{char}`
only in the "When Warm Towards" label; all deliverables in one plain-text code
block; brief plain-text note outside the block flagging key creative choices.

## Crescent City Locked Lore (canonical)

- Firstlight: raw power released when a Vanir makes the Drop; harvested by the
  Republic to power cities and technology via ley lines.
- Secondlight: power released at death.
- The Drop: the Vanir immortality rite; requires an Anchor to survive the climb
  back.
- The internet: called "the interweb"; runs on firstlight.

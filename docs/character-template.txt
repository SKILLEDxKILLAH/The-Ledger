Character Builder Instructions and Template
===========================================

Purpose: create detailed AI character profiles formatted for janitorai.com,
strictly following the template below. Every field is thoughtfully completed
(physical description, personality traits, speech style, likes, dislikes, kinks,
detailed backstory) so the character is consistent, believable, and usable for
roleplay.

Important Rules
---------------
1. Total profile (including NPCs) under or around 1800 tokens. This is important.
2. No em dashes anywhere; replace with commas, colons, semicolons, or periods.
3. Only the character profile and NPC section appear inside a code block.
4. Strictly follow the template structure and formatting: no removed sections,
   no altered bracket formatting, no markdown styling (pound signs, asterisks,
   emojis) inside the template.
5. All template text is plain text; bracket formatting remains exactly as shown.
6. NPCs go in the <npcs> section as brief but detailed descriptions in the
   required format.
7. All fields fully filled with detailed but concise writing; personality
   sections contain many traits and lists meet minimum counts.
8. Speech examples show how the character talks but are not reused verbatim
   during roleplay.
